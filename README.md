# 🚀 WebLibre — Plataforma SaaS de Landing Pages Anti-Errores

[![TypeScript](https://img.shields.io/badge/TypeScript-5.6-blue?logo=typescript)](https://www.typescriptlang.org/)

**WebLibre** es una plataforma SaaS (Software as a Service) enfocada en la creación hiper-simplificada y guiada de landing pages y sitios institucionales, diseñada para emprendedores y profesionales sin conocimientos técnicos.

---

## ✨ Características Principales

- **🧱 Constructor Visual por Bloques (Estilo LEGO)**: Ensambla secciones prearmadas (Hero, Galería de Medios, Beneficios, Cupones Promocionales, Pie de Página) con edición directa de texto (*inline editing*).
- **🎨 16 Paletas Cromáticas Armónicas & 9 Pares Tipográficos**: Sistema "anti-errores" que calcula automáticamente el contraste del texto para garantizar estética perfecta y excelente legibilidad.
- **📐 Sliders Geométricos de Bordes y Sombras**: Control preciso del nivel de curvas (`0px` a `28px` cápsula) e intensidad de sombras 3D.
- **📱 Previsualizador Multidispositivo**: Alterna instantáneamente entre vista **Desktop (100%)**, **Tablet (768px)** y **Mobile (375px)** con marcos de dispositivos reales.
- **📖 Animación de Libro 3D & Giro de Tarjeta 180°**: Paquete de 5 animaciones profesionales seleccionables, carrusel de hoja de libro 3D realista y tarjetas 3D con giro a 180°.
- **🎟️ Generador Autónomo de Cupones**: 3 diseños base (Ticket perforado, Card Neumórfica, Banner Minimalista) con actualización en tiempo real y animación de confeti.
- **💬 Burbuja de Contacto Directo WhatsApp**: Configuración de 1 solo paso con redirección instantánea a `https://wa.me/` y botón flotante de desactivación rápida en 1 clic.
- **🔍 Módulo SEO Guiado con Vista Previa de Google**: Simulador Snippet de Google, cálculo de Score SEO (0-100%) y meta-tags dinámicos.
- **🎁 Pop-up de Bienvenida con GIF Animado**: Cartel emergente editable con imagen o GIF animado.
- **📱 Generador de Código QR Integrado**: Descarga directa de Código QR vectorial en PNG HD.
- **💾 Copia de Seguridad JSON & Plantillas de 1 Clic**: Exporta e importa la configuración completa en un archivo JSON o carga plantillas por rubros (*Gastronomía*, *Estudio*, *Salud*).

## 🛠️ Tecnologías Utilizadas

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Serverless API Routes)
- **UI & Estilos**: [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/)
- **Iconos**: [Lucide React](https://lucide.dev/)
- **Efectos**: Canvas Confetti, HTML5 Canvas Image Compression API
- **Despliegue**: Optimizado para [Vercel](https://vercel.com/)

## 🚀 Instalación y Ejecución Local

### 1. Clonar el repositorio
```bash
git clone https://github.com/tu-usuario/weblibre.git
cd weblibre
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Iniciar el servidor de desarrollo
```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la plataforma.
